# Driver Drowsiness Detection

A real-time computer vision system that detects driver drowsiness and provides alerts to improve road safety.

## Features
- Monitors eye closure and facial movements for signs of drowsiness
- Provides real-time alerts to via audio or visual cues to warn the driver
- Built with OpenCV and Haar Cascade Classifiers

## Setup & Usage

```bash
# Clone the repository
git clone https://github.com/chasemaster72/Driver-Drowsiness-Detection.git
cd Driver-Drowsiness-Detection

# Install dependencies
pip install -r requirements.txt

# Run the detection script
python drowsiness_detection.py
